## MATLAB live scripts

Live scripts (`.mlx`) for the examples of the book, with the results (values and figures) stored
inside each file. They are the scripts in `../Matlab`, split into sections, with notes that connect
the code to the examples and conclusions of the book.

To view a live script, download it and open it in MATLAB (R2025a or later). To rerun it, keep this
folder as the current folder: the scripts read `Data/` and use the functions in `Support/`.
